=== 2026-10-03: VRAM measurement method ===
Tool: scripts/measure_vram.ps1 (written and self-tested; not yet run on a model).
Counter: Windows "GPU Adapter Memory" / "Dedicated Usage", read via .NET PerformanceCounter
  (Get-Counter blocks ~1 s per call, so it is too slow to catch a peak).
Adapters seen: two (dedicated GPU ~1.1 GiB at idle, integrated GPU 0 MiB). The script tracks
  both and reports the adapter whose usage rose the most.
Procedure per model file:
  1. Close other GPU programs (browser, games).
  2. Run the script, wrapping the same llama-bench command used for the speed test:
       .\scripts\measure_vram.ps1 -Label <quant> -Exe <path>\llama-bench.exe `
         -Arguments '-m models\<file>.gguf -ngl 99 -p 512 -n 128 -r 3'
  3. Record: idle, peak, delta (= model VRAM cost). Output also saved in results\logs\<quant>.txt
     and appended to results\vram_log.csv.
Self-test (command: ping, no GPU load): idle 1.133 GiB, peak 1.136 GiB, delta 0.003 GiB, 19 samples,
  exit code 0 -> script logic works; counter noise is about 0.003 GiB.
